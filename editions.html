How to read this comparison

Matching uses written names and physical modules in two pinned Git trees. Common declarations retain their original subject coordinates. An edited module may contain unchanged proofs. A cross-module match requires a unique original name and exactly one unmatched destination.

Repeated private names may remain unmatched after a move. New and ambiguous destination names have exact source links in the source-section index. Endpoint dependencies and proof paths are available for the original submission in the proof atlas. The edition maps measure written source.
