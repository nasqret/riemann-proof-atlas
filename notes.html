Where the RH proof goes

Following references from proof and definition values in riemannHypothesis reaches 647,905 individually identified written declarations. The overlay places 640,546 of these across 16 arXiv subjects, including contextual assignments. The remaining 7,359 have source links in named sections. The three largest assigned subjects are number theory (175,450), commutative algebra (140,147) and rings and algebras (131,517).

One arithmetic construction supplies a local–global Galois parameter. On the analytic side, a Landau argument constrains poles using a window estimate. Another lemma passes from that estimate to a zero-free region. Each link opens a specific theorem where you can inspect the printed Lean statement and its proof dependencies.

Paper Sky

Leland McInnes supplied a fitted F2LLM-v2-8B map of 3,080,258 title-and-abstract rows. The nine levels of Toponymy assignments yield 28,977 named regions. Each region opens to its paper count, observed memberships, and examples from the supplied table.

The mathematics filter selects 549,618 rows whose arXiv IDs match a primary mathematics category in the earlier archive. Papers without a verified primary category remain available in the full Paper Sky catalogue.

Proof groups are attached to 77 supporting papers found by exact arXiv ID in both editions. The inspector distinguishes direct theorem evidence from navigation through an enclosing proof. Spatial proximity gives subject context. Open a declaration to inspect the original Lean lines or follow its direct dependencies.

Paper Sky uses 21 colors for named topic regions. The legend gives each region’s paper count and opens its place on the map. Two neutral colors distinguish other named topics from papers without a name at any of the nine levels. Color key.

The Sernau compact edition

The final stop on the Proof evolution slider opens the compact rewriting in lsernau/grh-lean. Its two Lake projects share one Git commit. The readable project has the same Lean source tree as the earlier community readable import. The compact project contains a further rewriting of the argument. Proof evolution places it last for comparison. Daily history retains the chronological order of the community revisions. Read the four-page account of the condensed proof (PDF).

The original submission has 204.0 times as many Lean code lines and 97.5 times as many written declarations as the compact edition. Within Sernau’s repository, the readable edition has 3.94 times as many code lines as the compact edition. Each count uses the Lean files under the project’s src directory. A code line contains at least one token outside comments. Physical lines include comments and blank lines. Mathlib is an external dependency.
